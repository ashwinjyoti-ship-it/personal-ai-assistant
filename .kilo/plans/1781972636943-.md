# Chat Log Thread Card & Action Buttons Layout Plan

## Current State

A recent refactor (`f91bbf4`) updated `public/static/karna.css` and `src/frontend/threads.ts` to move the archive/delete action buttons out of the `.row-body` column and changed `.thread-item-actions` to `flex-direction: row`.

**However, the built asset at `dist/static/karna.css` is stale and still contains the old `flex-direction: column` + `padding-top: 4px` rules.** This is why the buttons still appear stacked vertically in the running app. The source changes are correct, but they were not propagated to `dist/`.

## Goal

Make the chat-log thread list feel compact and polished:
- Archive/delete buttons should sit inline with the thread title, not stacked below the content.
- Reduce the empty space between thread cards.
- Keep each thread as a distinct card.
- Ensure the built `dist/` assets reflect the changes.

## Chosen Approach: Option B — Actions inline with the title row

### `src/frontend/threads.ts`
For the non-select-mode thread item, move the action buttons into `.row-top` and drop the right-edge chevron (it is redundant because the whole card is clickable).

Current structure (lines 101–113):
```html
<button class="row thread-item ...">
  <span class="icon-well">...</span>
  <span class="row-body">
    <span class="row-top"><span class="row-title">...</span><span class="row-time">...</span></span>
    <span class="row-preview">...</span>
    <span class="row-badge">...</span>
  </span>
  <span class="thread-item-actions">...</span>
  <span class="row-chevron">&#8250;</span>
</button>
```

Target structure:
```html
<button class="row thread-item ...">
  <span class="icon-well">...</span>
  <span class="row-body">
    <span class="row-top">
      <span class="row-title">...</span>
      <span class="row-time">...</span>
      <span class="thread-item-actions">...</span>
    </span>
    <span class="row-preview">...</span>
    <span class="row-badge">...</span>
  </span>
</button>
```

### `public/static/karna.css`
- `.card-group`: reduce `gap` from `8px` to `4px`.
- `.thread-item`: remove `margin-bottom: 4px` so the card-group gap is the only spacing.
- `.thread-item-actions`:
  - Keep `flex-direction: row`.
  - Remove `padding-top`.
  - Make buttons compact: `padding: 3px 6px`, `min-width: 26px`, `min-height: 26px`, `font-size: 12px`.
  - Add `align-self: center` so the group does not stretch with the card.
- Remove the now-redundant mobile override at `karna.css:2624`.
- Remove the `.row-chevron` styles if they become unused (optional, low priority).

## Build Step

Run `npm run build` so `dist/static/karna.css` and the bundled frontend are regenerated from `public/static/karna.css` and `src/frontend/threads.ts`.

## Verification

1. Run `npm run build` and confirm it completes without errors.
2. Inspect `dist/static/karna.css` to confirm `.thread-item-actions` uses `flex-direction: row` and has no `padding-top`.
3. Inspect the generated bundle to confirm the thread item HTML places `.thread-item-actions` inside `.row-top`.
4. Optionally start the local preview (`npm run build` + swap to `wrangler-local.jsonc` + `npx wrangler pages dev dist --local --ip 0.0.0.0 --port 3000`) and open the thread sidebar to visually confirm:
   - Archive/delete buttons are side-by-side on the title row.
   - Less empty space between thread cards.
   - Each thread remains a distinct card.
