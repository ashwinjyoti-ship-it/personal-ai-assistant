# Chat Log UI Fixes Plan

## Problems to Solve

### 1. Multiple threads in one tile (main bug)
In `src/frontend/threads.ts`, the `renderThreadGroup()` function (lines 77–118) renders all threads within a group as a flat HTML string joined by `<div class="row-divider">` separators — they share one wrapping `<div class="card-group">` container. The CSS for `.card-group .thread-item` strips individual card styling (no per-item border-radius/shadow), making multiple threads look like one tile with lines between them.

### 2. Archive/Delete buttons stacked vertically below the thread content
In `threads.ts` lines 108–111, `.thread-item-actions` is a child of `.row-body` (a column-direction flex container). The actions span (archive + delete buttons) sits at the bottom of the body column. In `karna.css` lines 2183–2189, `.thread-item-actions` uses `flex-direction: column`, stacking the two buttons vertically.

### 3. No per-thread title
The thread `title` field is already rendered in `row-title`, but the user wants a more prominent/dedicated title visible on each tile. Currently the title is there but appears as part of the row content. The issue is that the grouping puts threads inside a shared card — individual titles are already rendered, they just aren't visually separated as independent cards.

---

## Root Cause Analysis

The key structural issue is in how groups are rendered:
```html
<div class="card-group">
  <div class="section-header">Older</div>
  <!-- renderThreadGroup() output -->
  <button class="row thread-item">Thread A</button>
  <div class="row-divider"></div>
  <button class="row thread-item">Thread B</button>
  <div class="row-divider"></div>
  <button class="row thread-item">Thread C</button>
</div>
```

The `.card-group` CSS in `karna.css` lines 1435–1461 styles all thread-items inside it with no individual styling — they look like rows in a single card. Dividers between them look like separators within a tile.

---

## Fix Plan

### Fix 1: Each thread gets its own tile (in `karna.css`)

**Change** `.card-group .thread-item` styling to remove the shared-card visual. Instead of grouping items under one card background, each `.thread-item` should be its own standalone card with its full border-radius and shadow.

**File:** `public/static/karna.css` lines ~1446–1461

The `.card-group` wrapper will keep acting as a container with a label (section-header), but items inside won't be visually merged. Remove any CSS that flattens the `.thread-item` appearance inside `.card-group` (e.g., overriding border-radius or removing shadows).

Also remove `.row-divider` generation in `renderThreadGroup()` in `threads.ts` (line 89), since each thread is now a standalone card. The margin-bottom on `.thread-item` (4px) provides natural spacing.

### Fix 2: Archive/Delete buttons horizontal, aligned with thread content (in `karna.css` and `threads.ts`)

**Move `.thread-item-actions` out of `.row-body`** and make it a direct sibling inside `.thread-item` (alongside `.icon-well`, `.row-body`, `.row-chevron`).

Currently in `threads.ts` lines 102–114:
```
<button class="row thread-item" ...>
  <span class="icon-well">...</span>
  <span class="row-body">          ← flex column
    <span class="row-top">...</span>
    <span class="row-preview">...</span>
    <span class="row-badge">...</span>
    <span class="thread-item-actions">  ← currently INSIDE row-body (bad)
      archive btn
      delete btn
    </span>
  </span>
  <span class="row-chevron">...</span>
</button>
```

**Change to:**
```
<button class="row thread-item" ...>
  <span class="icon-well">...</span>
  <span class="row-body">          ← flex column (no actions here)
    <span class="row-top">...</span>
    <span class="row-preview">...</span>
    <span class="row-badge">...</span>
  </span>
  <span class="thread-item-actions">  ← sibling of row-body (good)
    archive btn
    delete btn
  </span>
  <span class="row-chevron">...</span>
</button>
```

**CSS change** in `.thread-item-actions`:
- Change `flex-direction: column` → `flex-direction: row`
- Remove `padding-top: 4px`
- Keep `align-items: center`

This makes the two action buttons sit horizontally side-by-side, vertically centered with the thread content.

### Fix 3: Each thread gets its own visible title (already present, but needs card separation)

Fix 1 (individual cards) already makes each thread's title clearly its own. The title is already rendered in `row-title` inside `row-top`. No additional title markup is needed once each thread is visually separated.

### `public/static/karna.css`
- **Lines 1435–1461** (`.card-group` + `.card-group .thread-item`): 
  - Remove `.card-group` background/shadow (the shared card visual disappears; each thread-item is its own card instead).
  - Remove `.card-group .thread-item` overrides that flatten items (border-radius: 0, border-left: none, box-shadow: none, background: transparent). Each thread-item should use its own standalone card styles.
  - Keep `.card-group` as a simple flex column container for layout (no visual styling).

## Expected Result

- Each chat thread (including those in the same date group like "Older") renders as its own distinct card with rounded corners and shadow.
- The section headers (Today / Yesterday / Older / Telegram) still group cards visually but don't merge them into one tile.
- Archive and Delete buttons appear horizontally side-by-side, vertically centered on the right side of each thread card.
- Each thread clearly shows its title in the card header.
