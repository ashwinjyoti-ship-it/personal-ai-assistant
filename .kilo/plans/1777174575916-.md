# Plan for Better Mobile/PWA Experience

## Goals
1. Improve loading speed for mobile users.
2. Enhance iPhone keyboard behavior.
3. Implement an offline shell for basic functionality.
4. Add home screen shortcuts.
5. Enable push notifications.
6. Optimize streaming performance.
7. Improve sidebar usability on mobile.

## Steps

### 1. Faster Loading
- **Audit current assets**: Use Lighthouse to identify bottlenecks.
- **Optimize images**: Compress and lazy-load images.
- **Code splitting**: Split frontend code into smaller chunks.
- **Service worker**: Cache critical assets for offline use.

### 2. Better iPhone Keyboard Behavior
- **Input focus handling**: Ensure keyboard doesn’t obscure input fields.
- **Virtual keyboard events**: Listen for `resize` events to adjust UI.

### 3. Offline Shell
- **Service worker**: Cache static assets and API responses.
- **Fallback UI**: Show a basic UI when offline.
- **Sync API calls**: Queue and retry failed requests when back online.

### 4. Home Screen Shortcuts
- **Update `manifest.json`**: Add `shortcuts` for common actions.
- **Dynamic shortcuts**: Allow users to pin frequently used features.

### 5. Push Notifications
- **Service worker**: Register for push notifications.
- **Backend integration**: Add endpoints to handle subscription and delivery.
- **User preferences**: Let users opt-in/out in settings.

### 6. Smoother Streaming
- **SSE optimization**: Reduce latency and improve reconnection logic.
- **Chunked responses**: Stream smaller chunks for better performance.

### 7. Better Sidebar on Mobile
- **Responsive design**: Collapse sidebar into a hamburger menu.
- **Gesture support**: Add swipe gestures to toggle sidebar.
- **Performance**: Ensure sidebar doesn’t impact rendering speed.

## Verification
- **Testing**: Use Chrome DevTools and iOS Simulator.
- **Metrics**: Track load times and user interactions.
- **Feedback**: Gather user feedback on new features.
