# Plan: Enhance Dashboard Cards Glassmorphism

## Objective
Update the dashboard cards (`.dash-card` and `.dash-card.dash-card-error`) in `public/static/karna.css` to have a stronger glassmorphism effect, making them more transparent to the underlying background image.

## Steps
1. **Modify `.dash-card` in `public/static/karna.css`:**
   - Decrease the `background` opacity to make it more transparent. Currently it's `rgba(252,248,240,0.75)`. Change it to `rgba(252,248,240,0.25)`.
   - Update `border` to give it a lighter, frosted edge: `border: 1px solid rgba(255,255,255,0.4)`.
   - Ensure `backdrop-filter: blur(14px)` (or increase to `16px`) is preserved for the glass blur effect.
   - Retain the subtle `box-shadow` for depth.

2. **Modify `.dash-card.dash-card-error` in `public/static/karna.css`:**
   - Decrease `background` opacity. Currently it's `rgba(248,238,234,0.80)`. Change it to `rgba(248,238,234,0.25)`.
   - Keep the red-tinted border but perhaps make it slightly more translucent: `border: 1px solid rgba(180,50,40,0.4)`.

3. **Verify:**
   - There's no build step required for `public/` files in Vite during dev, but we can restart or rely on Vite's asset serving. Since we only change CSS, the user can refresh to see the changes.
